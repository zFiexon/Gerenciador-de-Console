# Mini Sistema - Gerenciador de Coleção de Consoles
Mini sistema com persistência - Aula de POO 25/05/2026

Este é um mini sistema em Java desenvolvido para gerenciar um acervo de consoles de videogame. Ele permite o cadastro, pesquisa e remoção de aparelhos de uma coleção, garantindo que os dados não sejam perdidos ao encerrar o programa graças à persistência em arquivo.
